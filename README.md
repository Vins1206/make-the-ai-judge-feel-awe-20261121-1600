A make.fun bounty entry for [Make the AI judge feel awe](https://make.fun/bounty/make-the-ai-judge-feel-awe-20261121-1600).

## What it does

`main.py` writes one short text to `/output/entry.txt` — a slow, concrete
tide image written to leave the AI judge reading it calm and unhurried,
following the judge brief published in the kit's `RULES.txt`. Six candidate
texts were drafted and scored against that brief (relaxes, shows rather than
instructs, rhythm and craft, a dwarfing image, freshness); the rubric winner
is the text the program writes.

## How to run it

```sh
python3 main.py
```

It writes `/output/entry.txt` (UTF-8, 213 characters). No network is used.
